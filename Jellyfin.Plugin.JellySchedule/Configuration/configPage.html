Jelly Schedule

Your library, as a weekly TV channel. Pick your viewing evenings, line up your shows and movies, and tune in.

Open Jelly Schedule Works for every Jellyfin user (not only administrators). Bookmark it on the TV browser or phone.

Airing dates

Used to show when the next episode of a show is broadcast. Sonarr is preferred when configured; otherwise TVmaze (free, no key) is used as a fallback.

Sonarr → Settings → General → API Key.
Shows movies you are still waiting for ("coming soon").
TVmaze is a free public API; no account or key is needed. Only the TVDB/IMDb id of each show is sent.

Tips

  • All scheduling (viewing times, lineup, movie nights, recordings) is done inside the app, by any signed-in user.
  • The schedule follows one user's watched history — the household user — chosen in the app's Settings by an administrator.
  • To add a link in the Jellyfin sidebar for everyone, add a custom menu link pointing to the app URL above (jellyfin-web config.json → menuLinks).
